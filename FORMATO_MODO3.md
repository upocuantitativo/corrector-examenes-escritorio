## Instrucciones Detalladas

### 1. NOMBRE (Tercio Superior)
- Escribe el nombre en el **tercio superior** de la hoja
- Letra clara, MAYÚSCULAS preferible
- Tamaño grande (al menos 2-3 cm de altura)
- Puede incluir línea debajo

**Ejemplo**:
```
Nombre: MARIA LOPEZ
```

### 2. SÍMBOLOS (Dos Tercios Inferiores)

#### Organización
- Los símbolos deben estar **organizados en cuadrícula**
- De **IZQUIERDA a DERECHA**
- De **ARRIBA hacia ABAJO**

#### Símbolos a usar
- ✓ (checkmark) = CORRECTO
- X (equis) = INCORRECTO
- ~ (tilde/virgulilla) = PARCIAL

#### Tamaño y Espaciado
- Símbolos grandes: mínimo 3-4 cm
- Espaciado entre símbolos: mínimo 2-3 cm
- Marcador negro grueso
- Fondo blanco

## Consejos para Mejor Detección

### ✅ HACER
- Buena iluminación uniforme
- Símbolos grandes y claros
- Marcador negro grueso
- Fondo blanco sin arrugas
- Cuadrícula bien espaciada
- Nombre en letra de imprenta

### ❌ NO HACER
- Símbolos muy pequeños
- Símbolos muy juntos
- Marcador fino o gris
- Fondo con sombras
- Papel arrugado
- Nombre con letra cursiva difícil

## Ejemplo Foto Real

Coloca la hoja así frente a la cámara:

```
  ┌─────────────────┐
  │                 │
  │   [  HOJA  ]    │  ← Hoja centrada
  │                 │
  │   completamente │
  │     visible     │
  │                 │
  └─────────────────┘
```

**Distancia**: 30-50 cm de la cámara
**Orientación**: Hoja recta, no inclinada
**Encuadre**: Toda la hoja visible con margen
